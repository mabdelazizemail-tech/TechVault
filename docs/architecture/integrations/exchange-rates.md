# Exchange rates — ExchangeRate-API open access

Integration note required by CLAUDE.md §15. Decision record: ADR-038.

| Question              | Answer                                                                                                                                                                                                                                                                                          |
| --------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| What it is for        | Converting mission expenses (Committees, ADR-037) to US dollars at the rate of the moment each claim is submitted, so mission totals can be shown in one currency.                                                                                                                              |
| Adapter               | `platform/integrations/exchange-rates.ts` — the only code that knows the provider. Domain code calls `getUsdRates()` and receives units per 1 USD as exact decimal strings, or `null`.                                                                                                          |
| Endpoint              | `GET https://open.er-api.com/v6/latest/USD` (ExchangeRate-API "open access"). Response validated with Zod before use; rates must be quoted against USD (`USD` = 1).                                                                                                                             |
| Data that moves       | Inbound only: published exchange rates. Nothing about TechVault, its users or their expenses is sent.                                                                                                                                                                                           |
| Who owns the record   | The rate a claim used is copied onto the claim (`committees.mission_expenses.usd_rate`, `usd_rate_at`, `usd_rate_source`, `usd_converted_at`) and never changes after. The provider owns nothing in TechVault.                                                                                  |
| Authentication        | None. Open access needs no account or key.                                                                                                                                                                                                                                                      |
| Freshness             | The provider publishes once a day. The adapter caches the rates per process for an hour.                                                                                                                                                                                                        |
| Failure behaviour     | 3-second timeout. On failure the adapter logs a warning, returns the last good rates if it has any, otherwise `null`, and does not call the feed again for 5 minutes. A claim submitted without a rate is saved anyway and converted at that day's rate before the next page shows USD figures. |
| Rate limits and terms | The provider asks open-access users to cache and not to poll more than needed, and to credit it wherever its rates are shown: pages showing converted amounts link to <https://www.exchangerate-api.com>. Terms: <https://www.exchangerate-api.com/terms>.                                      |
| Replacing it          | Change only the adapter. The XE Currency Data API (paid, needs an account ID and key in configuration) is the named alternative if exact XE rates are required.                                                                                                                                 |
